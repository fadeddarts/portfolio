Designing tactile interfaces with rigid-body physics

Building KINETIC TYPE: when typography stops behaving like decoration and starts behaving like matter.

Most interface animation describes a journey between two known values. Physics begins with a state, applies forces, and lets the destination emerge.

Moving beyond duration and easing

A CSS transition is an excellent tool when an element needs to move from one known state to another. The browser interpolates the values for a fixed duration and stops. 

.card {
  transform: translateY(20px);
  transition: transform 400ms ease;
}

But the model has no natural concept of momentum. Two transitioning elements cannot collide. If a visitor grabs something halfway through, its apparent velocity is not part of the state.

KINETIC TYPE needed continuity. Letters had to carry velocity after being released, rotate when struck off-centre, bounce against the viewport, push each other apart, and still remember where the word belonged.

Mapping HTML glyphs to physical bodies

The visible glyphs remain ordinary HTML spans. This keeps browser-quality font rendering and preserves the option to expose meaningful text to assistive technology. A separate JavaScript object holds each letter’s physical state. 

const body = {
  element,
  position: { x, y },
  velocity: { x: 0, y: 0 },
  angle: 0,
  angularVelocity: 0,
  radius: glyphSize * 0.31,
  mass: 1,
  anchor: { x: baselineX, y: baselineY }
};

The solver knows nothing about typography. It only sees a body with position, mass, velocity, rotation, and a collision radius. During rendering, that state becomes a GPU-composited transform: 

body.element.style.transform = `
  translate3d(
    ${body.position.x}px,
    ${body.position.y}px,
    0
  )
  rotate(${body.angle}rad)
`;

I use circular collision bounds rather than attempting to trace each glyph outline. The approximation is cheaper, stable, and visually forgiving. Perceptual credibility matters more here than typographic collision precision.

Keeping simulation time stable

Physics becomes unpredictable when a dropped frame suddenly creates a huge time step. At minimum, elapsed time needs to be measured and clamped: 

let previousTime = performance.now();

function frame(now) {
  const delta = Math.min(
    (now - previousTime) / 1000,
    1 / 30
  );

  previousTime = now;
  updatePhysics(delta);
  renderBodies();
  requestAnimationFrame(frame);
}

A larger system can accumulate elapsed time and execute several fixed 1 / 60 updates before each render. For KINETIC TYPE, a clamped step keeps the interaction stable while remaining simple enough to inspect and tune directly.

Making the word shatter with intention

Scattering letters with completely random vectors produces noise, not impact. The shatter needs a readable centre and directional rhythm, with randomness added only as texture. 

function shatter(bodies) {
  const centre = (bodies.length - 1) * 0.5;

  bodies.forEach((body, index) => {
    const offset = index - centre;
    const spread = offset * 1.4;
    const power = 420 + Math.random() * 180;

    body.velocity.x += Math.sin(spread) * power;
    body.velocity.y -= Math.cos(spread) * power;
    body.angularVelocity +=
      (Math.random() - 0.5) * 8;
  });
}

Once the impulse has been applied, gravity and collisions take control. The animation is not replaying a timeline. It is resolving the consequences of an event.

The harder problem: reforming the baseline

Every glyph retains an anchor representing its original place in the word. Reforming applies a damped spring force rather than tweening the current transform back to zero.

Fspring = −k(x − xanchor) − cv

The first term pulls the body toward its anchor. The second resists its current velocity. In code: 

function applyAnchorSpring(body, stiffness, damping) {
  const dx = body.anchor.x - body.position.x;
  const dy = body.anchor.y - body.position.y;

  body.velocity.x += dx * stiffness;
  body.velocity.y += dy * stiffness;

  body.velocity.x *= damping;
  body.velocity.y *= damping;

  body.angularVelocity +=
    -body.angle * stiffness * 0.6;

  body.angularVelocity *= damping;
}

A distant letter returns with more energy than one already near its target. A spinning letter can cross the baseline, overshoot, and settle. The word reforms as one system rather than seven identical transitions.

The interface remembers its composition, but it does not pretend the disturbance never happened.

Collision response without a heavyweight engine

Matter.js would be a reasonable choice for a larger scene. This experiment uses a smaller custom impulse solver so the relationship between the numbers and the feel remains visible. 

const dx = b.x - a.x;
const dy = b.y - a.y;
const distance = Math.hypot(dx, dy) || 0.001;
const overlap = a.radius + b.radius - distance;

if (overlap > 0) {
  const nx = dx / distance;
  const ny = dy / distance;

  a.x -= nx * overlap * 0.5;
  a.y -= ny * overlap * 0.5;
  b.x += nx * overlap * 0.5;
  b.y += ny * overlap * 0.5;

  const relative =
    (b.vx - a.vx) * nx +
    (b.vy - a.vy) * ny;

  if (relative < 0) {
    const impulse = -relative * restitution;
    a.vx -= nx * impulse;
    a.vy -= ny * impulse;
    b.vx += nx * impulse;
    b.vy += ny * impulse;
  }
}

Separating overlapping bodies prevents them from sinking into one another. Applying an impulse along the collision normal changes their velocity. A small rotational impulse makes off-centre impacts visible.

Damping, friction, and the design of weight

Tiny numerical changes produce large emotional differences. These constants are not merely engineering parameters; they form the material palette of the interaction.

Damping

High damping removes energy quickly and feels controlled or soft. Low damping permits oscillation and feels elastic, nervous, or mechanical.

Friction

Friction determines how long a glyph slides after reaching the floor. High friction feels rubberized and heavy. Low friction suggests polished metal or glass.

Restitution

Restitution defines how much velocity survives a collision. Zero feels dead; one approaches a perfectly elastic bounce. Around 0.6 gives the letters enough life without turning the composition into a pinball table.

Angular damping

Rotation carries a disproportionate amount of character. Too little damping makes letters look weightless. Too much makes collisions feel fake because bodies translate without reacting rotationally. The correct range also depends on the typeface.

Physics as interface language

The point is not to make every interface bounce. Physics is useful when continuity matters—when people drag, throw, stretch, collide with, or disturb something.

Consistent physical rules create trust. Once one letter reacts to the pointer, the visitor forms an expectation about the next. They begin experimenting without needing an instruction panel.

KINETIC TYPE is still typography. It has hierarchy, baseline, contrast, and rhythm. Physics does not replace graphic design. It gives the design a temporary material state.
