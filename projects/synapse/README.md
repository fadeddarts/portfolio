# Synapse

Generative neural mesh with pointer forces, edge pulses, and optional Web Audio reactivity.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173/`.

## Deploy standalone

Copy this folder into its own repository and enable GitHub Pages from the repository root.
No build step or parent-site dependency is required.

## Embed mode

Append `?embed=1` for a compact chrome-free preview suitable for iframes.
