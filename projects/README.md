# Standalone projects

Each directory is an independent static application with its own HTML, CSS, and JavaScript:

- `aether/`
- `kinetic-type/`
- `synapse/`
- `chronos/`
- `blender-art-lab/`
- `minimalist-raycaster/`
- `currents/`

To publish one project separately, copy that directory into its own repository and enable GitHub
Pages from the repository root. No build step or parent-site dependency is required.

Every project also supports `?embed=1`, which is used by the main portfolio for compact previews.
